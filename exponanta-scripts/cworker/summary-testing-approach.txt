Slugify as a non-core addon

CW-slugify.js is a separate, optional file (292 KB, about 90 KB gzipped).

Contents: the transliteration library bundled by esbuild, plus the 17 character replacements (@ → -at-, . → -dot-, and so on).
API: it defines CW.slugify synchronously.
Fallback: the core (generateSlug in CW-utils.js) uses CW.slugify if it exists. Without it, it falls back to a simple regex slug, so the core still runs.
Limit of the fallback: without the addon, non-Latin text such as Russian or Kazakh gets a poor slug.
Worker: it only takes effect if worker.js has import "./CW-slugify.js". I still can’t confirm that line is in your current worker.js.
