Issue
Existing users logging in via LinkedIn OAuth got #error=[object Object] instead of #token=. New users worked because create succeeded and _issueToken fired automatically. Existing users hit UNIQUE constraint, create failed, and the fallback used run_doc.child({ operation: "select" }) which runs through ACL — unauthenticated context, so it returned nothing, doc was undefined, causing a crash.

Fix
Replaced the ACL-gated select child call with a direct D1 query — same pattern as login uses — bypassing ACL entirely. Safe because LinkedIn already verified the user's identity before this code runs.
