Summary — User Auth & OAuth Implementation
User Schema — CW.Schema.User

Key fields:

email — reqd, in_local_view: 1, in_list_view: 1
full_name — in_local_view: 1, read_only: 0
user_image — in_local_view: 1
password — fieldtype: 'Password', not virtual — stays in target.data[0] for login
providers — fieldtype: 'Code', options: 'JSON', read_only: 0 — stores full provider profile

_state dims:

status — default: 'Active', values: ['Invited', 'Active', 'Locked', 'Reset Pending', 'Disabled']
email_status — default: 'Unverified', values: ['Unverified', 'Verified']

userFields — CW-config.js
javascript
userFields: [
  {
    fieldname: 'password_hash',
    onCreate: async (run_doc) => {
      const doc = run_doc.target.data[0]
      if (!doc.password) return  // skip OAuth users
      doc.password_hash = await pbkdf2(doc.password)
      delete doc.password
    }
  },
  // ... owner, _allowed, _allowed_read, _state hooks
]

Security: password_hash skipped for OAuth users. Password login blocked for OAuth users via if (!doc.password_hash) guard in login.

D1 Adapter — CW-adapter-d1.js

Auth helpers:

pbkdf2(password, salt?) — per-user random salt, hex encoding, returns saltHex:hashHex
_buildUserPayload(doc) — reads in_local_view fields + FSM dims → JWT payload
_issueToken(doc, run_doc) — builds payload, signs JWT, sets run_doc.user

Auth operations:

login(run_doc) — verifies pbkdf2 hash, checks _state.status === 'Active', issues JWT. Guards: block if no password_hash (OAuth user)
logout(run_doc) — clears localStorage client-side
createUser(run_doc) — runs userFields.onCreate hooks, initializes _state, calls _d1Insert, issues JWT

HTTP operations:

oauthLogin(run_doc) — reads provider from target.data[0], builds Google/LinkedIn auth URL, sets run_doc.target.data[0].redirect_url
oauthCallback(run_doc) — exchanges code via cfg.mapParams, gets userinfo, calls cfg.mapUser, creates/finds User via run_doc.child(), issues JWT, sets token and return_url on doc
cwPost(run_doc) — passthrough, success: true
shell(run_doc) — passthrough, success: true

Adapter surface:

globalThis.Adapters['d1'] = {

  login, logout,
  oauthLogin, oauthCallback, cwPost, shell,
}
Worker — worker.js
javascript
// POST — CW operation dispatch
if (req.method === 'POST') {
  const run_doc = await req.json()
  run_doc.user  = await verifyJWT(req.headers.get('Authorization') || '', env.JWT_SECRET)
  const op      = { operation: run_doc.operation }
  CW._resolveAll(op)
  await globalThis.Adapters[op.adapter]?.[run_doc.operation]?.(run_doc)
  return Response.json(run_doc, { headers: CORS })
}

// GET — route dispatch
for (const route of CW._config.routes?.filter(r => r.method === 'GET') || []) {
  if (!new URLPattern({ pathname: route.path }).exec(url)) continue
  const run_doc = await CW.run({
    operation:      route.operation,
    target_doctype: 'Http',
    input: {
      provider:   route.provider,
      code:       url.searchParams.get('code'),
      state:      url.searchParams.get('state'),
      return_url: url.searchParams.get('state')
        ? new URL(atob(url.searchParams.get('state')), url.origin).href
        : url.origin + '/',
    },
    autosave: 0,
    options:  { render: false }
  })
  const doc = run_doc.target?.data?.[0]
  if (route.operation === 'shell')         return env.ASSETS.fetch(new Request(new URL('/shell.html', url)))
  if (route.operation === 'oauthLogin')    return run_doc.success ? Response.redirect(doc.redirect_url, 302) : new Response(run_doc.error, { status: 404 })
  if (route.operation === 'oauthCallback') return run_doc.success ? Response.redirect(`${doc.return_url}#token=${doc.token}`, 302) : Response.redirect(`${doc?.return_url || '/'}#error=${encodeURIComponent(run_doc.error)}`, 302)
}
Client — shell.html

Token extraction on page load:

javascript
const _oauthToken = new URLSearchParams(window.location.hash.slice(1)).get('token')
if (_oauthToken) {
  const _payload = JSON.parse(atob(_oauthToken.split('.')[1]))
  globalThis.currentUser = { ..._payload, token: _oauthToken }
  localStorage.setItem('currentUser', JSON.stringify(globalThis.currentUser))
  window.history.replaceState({}, '', window.location.pathname)
}

Key invariants
auth_provider derived from Object.keys(doc.providers)[0] — no separate field
JWT payload = in_local_view fields + FSM dims — same shape for all auth methods
localStorage.currentUser = JWT payload + token — single client store
password_hash skipped for OAuth users — if (!doc.password) return
Adding new provider = one oauth config entry + two route entries — zero code changes
